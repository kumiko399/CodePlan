# CodePlan 0.1.0

首个公开源码版本，面向计算机专业学生的个人 Windows 计划工具。

## 功能

- 今日任务、14 类大学生活分类、子任务、截止日期、回收站、月历／周历和 emoji 标记。
- 专注记录、学习统计、算法题资料与解题笔记、每日／每周复盘。
- 本地 MySQL 持久化、备份恢复、草稿保护、重复任务和可选通知。
- 多城市天气、24 小时及 7 天预报、指标详情、单位设置与任务天气参考。

采用自定义非商业源码许可（见 LICENSE），不是 MIT 或 OSI 开源许可证。允许个人学习与非商业教学研究；商业使用须另获书面授权。

预报数据来自 [Open-Meteo](https://open-meteo.com/)，按 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)署名；城市检索使用 Open-Meteo / GeoNames，主动启用的 IP 定位使用 ipwho.is。数据经过单位换算、时间转换、取整及图表／emoji 映射，穿衣和舒适度是应用参考建议。数据供应商不为本应用背书。

## 发布范围与限制

本次只提供源码。自动生成的 ZIP / tar.gz 为源码归档，不是可直接运行的安装包。MySQL／Connector/J、Java 和微软运行库的组合分发授权及对应源码义务仍待审核，因此不上传 EXE、JAR 或运行库。

0.1.0 为首次公开源码编号，本机内部测试安装曾使用 1.1.1；不表示对已有个人数据库执行降级。数据库迁移版本及备份格式保持原有兼容规则。

开发运行步骤见 README。未完成干净 Windows 机器的安装验收及可见原生拖放实测；不承诺用于高风险气象决策。GitHub 源码发布不代表所有第三方安装包分发问题已解决。
