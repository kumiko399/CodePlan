# CodePlan 0.1.1 · 首页离线黄历

在首页新增可切换日期的黄历小窗口，查看公历、完整农历和传统宜忌，无需联网，也不会改变任务日期或天气城市。

## 新增功能

- **简洁撕页日历**：大号公历日期、年月和星期，完整农历日期明确显示闰月；宽屏位于首页右上角，窗口小于 1280px 时移到操作区下方、天气摘要之前。
- **传统宜忌**：绿色“宜”和暖红色“忌”均保留文字标签，每栏默认显示前三项，可展开全部或收起；不提供随机运势评分。
- **日期浏览**：前一天、后一天、日期选择器和“回到今天”，支持 1901—2099 年，边界禁止继续翻页。
- **自动校准**：跟随今天时跨午夜自动更新，恢复焦点或页面可见性时校准；浏览其他日期时保留选择，重新进入首页恢复今天。
- **界面适配**：深色主题、键盘操作及英文按钮和说明；农历与传统宜忌词条保留中文。卡片自身没有动画。

## 可靠性与数据来源

- 使用固定版本 [lunar-javascript 1.7.7](https://github.com/6tail/lunar-javascript)，按本机公历日期在前端离线计算，每日宜忌固定采用流派 1。
- 保留库返回的“无”；遇到异常显示不可用，不编造内容。卡片不增加 HTTP 接口、数据库字段、备份格式或定位请求。
- MIT 许可原文、作者署名和数据来源入口已补齐。宜忌仅为民俗参考，各黄历来源可能存在差异，不是官方认证或科学预测。
- 农历样例使用香港天文台公农历对照表交叉核对；该历表不是宜忌来源。上游数据来源与再分发限制见 [DATA_SOURCES.md](https://github.com/kumiko399/CodePlan/blob/v0.1.1/docs/DATA_SOURCES.md)。

## 验证

30 项规则测试与 41 项后端测试通过；日期规则覆盖春节前后、农历闰月、公历闰日、范围边界、异常降级和同日稳定性。前后端生产构建及隐藏 Electron 界面验收通过，覆盖日期选择、展开收起、断网、深色、英文、键盘以及首页保存／新增任务／天气入口回归；本机安装包与实际安装程序也通过隔离验收。

跨午夜和恢复场景使用可控时钟及焦点／可见性事件模拟，未进行真实设备休眠和干净 Windows 虚拟机安装验收。
