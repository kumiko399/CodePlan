- 本轮不自动提交、推送或更新安装版；再公开前复核宜忌数据再分发条件，版本和标签不变。

## 产品形态

Windows 11 x64 单人桌面应用，无应用账号，离线可用，数据保存在本机。Vue 3 + JavaScript 前端，Java 21 + Spring Boot + MyBatis 后端，MySQL 数据库，Electron 提供桌面能力。最终安装包包含专用 Java、MySQL，不要求用户配置现有数据库。

## 现有功能基线：任务规则（已实现）

- 首页提供「保存数据」按钮：已有任务修改即时写入数据库；该按钮额外生成一份可恢复的本地手动备份，显示进行中、成功时间与失败重试提示，不保存仍在弹窗中未提交的草稿。
- 必填标题（1～100 字）、分类、计划日期；可选时间、备注、提醒时间；优先级高／中／低。
- 状态待完成／进行中／已完成；完成时记录时间，重新打开清除完成时间。
- 计划日期早于今天且未完成属于「计划延期」；超过明确截止时间且未完成属于「截止超期」，两者同时满足时优先显示截止超期；不自动顺延。
- 修改任务日期后只保留一条记录；删除需明确确认。
- 日期格最多显示三项，超出显示剩余数量；分类颜色与文字同时提供，完成项有勾选标记。
- 分类共 14 项：📚学习、🏠生活、🏃运动、🧩算法、🎓课程、📝作业、🎯考试、📖阅读、💻项目、🎨社团、🤝社交、🍱饮食、🌙休息、💼实习求职。原分类标识与数据保留。
- 日历月视图每格最多三条单行任务摘要，保留分类色条与一个 emoji，长标题省略并可悬停查看完整文本、分类、时间和截止信息；周视图最多五条双行摘要。超出数量显示「还有 N 项」。今天使用圆形日期标记，选中日期使用边框，已完成淡化并打勾，逾期未完成显示警示。深色模式保留分类对比度。
- 点击日期、任务条或剩余数量打开当天完整安排：宽度至少 1440px 时为右侧面板，否则为抽屉，包含完整标题、分类、状态、截止时间、备注、子任务及编辑／完成／删除／每日复盘。编辑后保持当前月份；日期格的「＋」在悬停或键盘聚焦时显示，自动带入当天日期。
- 日历上方可按分类、状态、优先级筛选或隐藏已完成，筛选同时作用于格子和当天详情，展示筛选条件并可清除。月历以完整周显示，去掉不包含本月日期的多余末行。
- 日历用橙色「↗ 计划延期」与红色「! 截止超期」区分提醒；悬停显示具体日期／截止时间及未完成原因，当天详情同步显示文字说明，已完成任务不再显示警示。图标与分类 emoji 分开。
- 延期或超期任务的当天详情提供「移到今天」「改期」「标为完成」。计划已在今天时禁用「移到今天」；改期对话框支持选择日期。改期前读取最新任务，只改计划日期，保留备注、状态、图标、子任务和截止时间；新的计划超出截止时间时明确确认，取消不写入。截止超期任务提示编辑截止时间，改期不自动清除原截止时间。快捷改期沿用 15 秒撤销。
- 月／周日期格及当天详情显示「完成 X/Y」与细进度条，按当天全部正式任务计算，不受分类／状态／优先级／隐藏完成筛选影响；筛选时另列显示数量。空白日期不显示 0/0；完成、改期、撤销后同步刷新。
- 普通单次任务及重复任务的当前实例可从预设 emoji 中选择专属图标，不选则跟随分类；不改变稳定分类 ID。图标跟随编辑、回收站恢复和业务备份保留。重复规则及模板创建仍使用分类默认图标。
- 每天最多一篇纯文字复盘；点击保存持久化，清空并保存删除。离开未保存编辑时提示。

## 现有功能基线：算法规则（已实现）

- 题目、每天的计划、实际解题记录分别保存。同题可重复练习，但同题同日不重复安排计划。
- 题目包含平台、题号、名称、http(s) 链接、难度、多知识点与文字／Markdown 原文笔记。
- 解题记录包含实际时间、通过／未通过、选填用时、思路或代码原文。
- 新增通过记录可完成关联计划；新增失败记录将未完成计划标记为进行中。修改、删除历史解题记录调整统计，不自动撤销任务状态。
- 手动完成任务不计作题目通过；所选时间段内，同一道题多次通过只计一道通过题。
- 任务按计划日期统计，刷题按实际记录日期统计。知识点允许一题多计，因此总和可能高于通过题数。
- 删除任务保留题目及解题记录；已有引用的题目不能直接删除。
- 不做算法复习计划。力扣中国同步没有经验证的稳定接入方案，当前版本不提供同步入口。

## 现有功能基线：自动化与桌面（已实现）

- 六个导航入口支持悬停与键盘焦点浮动效果；保持当前页面高亮，系统偏好减少动画时禁用位移与缩放。
- 重复任务、桌面提醒、自动备份分别开关，默认关闭。
- 重复规则支持每天／指定星期、开始日期、可选结束日期。每次完成状态独立。
- 开启后生成未来 30 天；应用运行时补充。关闭不删除已有实例，重新开启不补关闭期间的日期。
- 同一规则同一天最多一个实例，手动删除的实例不因普通维护重新生成。
- 规则编辑替换今天及未来未完成实例，保留完成历史；单个任务可只修改本次。
- 最多补齐过去一年的未生成实例，防止多年未打开后一次生成海量任务；这个实现上限不影响正常日常使用。
- 应用驻留托盘时才提供提醒；退出后停止。错过的提醒汇总为一条，不集中弹窗。
- 设置页提供「窗口行为 → 关闭窗口时」，选择「最小化到托盘」或「直接退出」，选择后自动保存，默认最小化。点击关闭按钮或 Alt+F4 直接执行已保存的选择，不再弹出关闭方式询问。启动期无托盘时最小化到任务栏；重新打开时恢复窗口。本机偏好在应用重启后保留，不纳入业务备份，浏览器模式不显示此设置。
- 完全退出或托盘退出时依次结束专属服务，等待 MySQL 完全退出，不重复询问。选择最小化保留服务及未提交表单；完全退出前应先保存未提交的编辑。

## 现有功能基线：备份恢复（已实现）

- 备份目录可选；数据库工作目录由应用管理，不提供迁移按钮。
- 手动备份与每日自动备份为 ZIP 文件，包含 `manifest.json` 和 `data.json`、格式版本及 SHA-256 校验和。
- 每日最多一份自动备份；保留最近 30 份，手动及恢复前备份不自动清理。
- 快照含任务、规则、题目、解题记录、复盘和通用设置；不含密码、令牌、备份路径等本机配置。
- 恢复先上传并验证、显示数量与时间，再由用户确认覆盖。先创建保护备份，再在数据库事务中替换全部业务表。
- 文件损坏、版本不兼容、引用不完整、恢复前备份失败时拒绝操作；数据库写入失败时回滚，旧数据保持完整。
- 第一版备份上限 20 MB（含解压数据限制），不支持合并恢复或附件。

## 第一版新增需求（本轮已实现）

目标：让计划更容易完成，让学习投入可回顾，同时减少重复输入和误删损失。以下功能均纳入第一版范围，按依赖逐项实施。

### F01 子任务清单

- 在任务详情中新增、编辑、勾选、排序和删除子任务，第一版只支持一层，不支持无限嵌套。
- 任务列表和详情显示“已完成子任务数／总数”；没有子任务时不显示该进度。
- 子任务完成情况与父任务状态分开记录。全部子任务完成时提示可完成父任务；父任务仍有未完成子任务时，完成父任务需确认，不静默改写子任务状态。
- 父任务改期不复制子任务；进入回收站和恢复时，子任务随父任务一起处理。重复任务的每个实例拥有独立的子任务完成状态。
- **验收**：刷新和重启后顺序、内容、勾选状态保持；修改一项重复任务的子任务不影响其他日期的实例。

### F02 截止日期与首页临近到期区

- 任务增加可选截止日期、可选截止时间。计划日期表示“准备哪天做”，截止日期表示“最晚何时完成”，二者独立保存。
- 截止日期未填写时，不显示倒计时；只填写日期时按本机当天结束判断。完成任务退出临近到期列表。
- 首页新增“临近到期”，默认展示未来 7 天到期的未完成任务，并提供查看全部入口；区分今天到期、剩余天数和已超截止时间。
- 区分“计划已逾期”和“已超截止时间”，避免把普通学习计划误显示为作业交付超时。
- 修改计划日期不改变截止日期；计划排在截止时间之后时给出可理解的提醒，允许用户确认后保留。重复任务首期只给单个实例设置截止日期，避免套用同一个固定截止日。
- **验收**：跨月、跨年、午夜、只有日期与带时间的边界判断正确；完成或改期后首页、任务页、日历信息一致。

### F03 番茄钟与专注记录

- 从任务启动专注计时，默认专注 25 分钟、休息 5 分钟，允许在设置中调整；支持暂停、继续、提前结束及取消本次记录。
- 同一时间只能有一个活动计时器，切换任务前先处理当前计时。最小化到托盘后继续计时，阶段结束提醒遵守通知开关。
- 保存关联任务、开始时间、结束时间、实际专注时长与完成／中断状态；暂停和休息时间不计入专注时长。完成番茄钟不自动完成任务，也不计为算法通过。
- 完全退出时提示正在计时，允许结束并保存记录或取消退出。异常关闭或电脑休眠后，下次打开提示处理未完成记录，不把离线时间自动当作专注时间。
- **验收**：反复暂停继续、切换页面和最小化不重复计时或重复入库；取消记录不进入统计，跨日记录按实际专注区间归属日期。

### F04 回收站

- 普通任务删除改为移入回收站，支持查看删除时间、单项恢复与彻底删除；第一版暂不提供题目、解题记录等其他实体的回收站。
- 默认不自动清理；彻底删除需再次确认。回收站中的任务不显示在日常列表、日历、提醒和任务统计中，也不参与专注启动。
- 恢复时保留原任务标识、日期、分类、子任务及可恢复的关联；保留已有解题记录与专注记录，不因删除父任务而一并清除学习历史。
- 重复实例删除后不因自动生成而再次出现；恢复旧实例也不得制造同规则同日重复。遇到计划唯一性冲突时明确提示，不覆盖已有任务。
- 备份包含回收站数据。恢复过期任务时不立即补发一批旧提醒，由用户确认是否重新设置提醒。
- **验收**：移入、恢复、彻底删除和备份恢复后数据一致；重复实例不会复活或重复，算法通过数不因普通任务删除而改变。

### F05 常用任务模板

- 将一项任务或一组任务保存为模板，例如“考试复习”“每日刷题”“周末整理”。支持模板新增、编辑、删除和预览。
- 模板保存标题、分类、优先级、备注和子任务结构，不带入原任务完成状态、计时记录和历史解题结果。
- 创建时由用户选择基准日期，多任务模板可设置相对天数；预览将创建的任务、日期和数量，再确认一次性创建。
- 模板与生成任务相互独立，修改模板不回写已生成任务。遇到停用分类、失效题目关联或同题同日冲突时提示处理，不能静默遗漏任务。
- **验收**：一次创建全部成功或全部撤销；重复点击不会多建一批任务，模板修改不影响历史任务。

### F06 周视图与拖动改期

- 日历增加周视图，与月视图切换；周一作为一周起点，支持上一周、下一周和回到本周。
- 周视图继续显示任务名、分类 emoji、完成状态和截止信息；支持将任务拖到另一日期，只改变计划日期，保留时间和截止日期。
- 重复任务拖动只调整本次实例；同题同日冲突或目标日期晚于截止日时按现有业务规则提示，不静默覆盖。
- 保留任务编辑框中的日期修改方式，供键盘操作和不方便拖动的用户使用。请求失败时撤销界面的临时移动并说明原因。
- 拖动时高亮目标日期，写入成功后提示移动结果并提供 15 秒撤销入口。撤销读取最新任务，仅恢复计划日期，保留后来修改的标题、备注、状态与图标；任务已删除或再次改期时拒绝撤销。
- **验收**：跨月周显示正确；拖动后今日页、全部任务与日历一致，失败不会出现任务丢失或重复；一天 12 条任务不撑高格子，850px 窗口无横向溢出，深色与英文界面可读。

### F07 自定义分类

- 在现有 14 个预设分类之外新增自定义分类，填写名称、emoji、预设颜色；支持编辑展示信息与停用。
- 分类使用稳定标识，显示名称变化不改变任务引用。预设分类标识保持不变，算法分类的题目关联规则继续保留。
- 被引用的自定义分类不能直接物理删除，可停用；停用后不再用于新任务，但历史任务、统计、模板和备份仍能显示原分类。
- 日历、列表、筛选、重复规则、模板和统计统一读取分类定义。界面切换语言时，自定义名称保持用户原文，不显示内部标识。
- 分类定义及引用纳入备份；旧备份没有自定义分类时，自动补齐预设分类。
- **验收**：名称、emoji 和颜色修改后各页面同步；停用不会损坏旧记录，跨备份恢复仍能正确识别分类。

### F08 每周学习报告

- 统计页增加按自然周查看的学习报告，展示已完成任务、专注时长、尝试次数、去重通过题数、改期任务和未完成安排。
- 周期为本机时区周一至周日；任务按计划日期统计，专注按实际时间统计，解题按实际记录日期统计，页面明确说明口径。
- 同一题多次通过仍计一道。被删除的任务与保留的学习历史按各自规则统计，不能混算。
- 改期次数需基于真实改期记录，不能仅根据当前日期推断；报告中的计划变动情况随记录更新。
- 支持填写并保存一段本周复盘；没有数据时显示空状态，避免使用虚假的增长百分比或评价。第一版不生成 AI 总结。
- **验收**：切换周、周边界、重复刷题、补录和修改历史记录后报告正确；个人复盘重启后保留。

### F09 结构化解题笔记

- 题目笔记增加思路、时间复杂度、空间复杂度、易错点、代码及代码语言等独立区域，均可选填。
- 代码支持语法高亮和复制，只作为文本展示，不执行代码，不提供在线评测。
- 兼容现有自由笔记与解题记录原文，迁移时不丢失旧内容，也不尝试自动拆分而覆盖原文。
- **验收**：中文、缩进、换行及特殊字符保存后不变；代码内容不能被当作 HTML 或脚本执行，旧笔记仍可查看。

### F10 收藏与待攻克标记

- 为题目提供互相独立的“收藏”和“待攻克”标记，可同时开启，支持快速筛选。
- 标记与是否通过分开记录：通过题目不自动取消待攻克，收藏也不产生通过记录或新任务。
- 标记纳入备份，旧题目默认均未标记。
- **验收**：切换标记只改变标记及筛选结果，不改变任务状态、解题记录或通过统计。

### F11 算法知识点筛选

- 在算法题库增加知识点筛选，可结合难度、收藏、待攻克与是否通过条件查看题目。
- 多个知识点采用“任一匹配”，界面明确显示当前条件；无知识点题目有独立筛选入口。
- 显示当前筛选结果数，可一键清除条件；复用现有知识点数据，不维护第二套互不一致的标签。
- **验收**：一题多标签在列表中只出现一次；编辑标签后筛选结果立即更新，不影响原始通过统计。

## 交付与验收

先跑通浏览器中的任务 CRUD，再补日历／算法／统计、备份，最后完成桌面容器和安装包。每一阶段都应有可运行结果。

必须验证：任务持久化、跨月日期、重复规则去重、通知开关、刷题去重、备份恢复及失败回滚、界面语言主题、桌面服务退出。干净 Windows 安装和大数据性能需要专门环境实测，不能用单机开发验证替代。

扩展功能开发后，每完成一项先检查其验收条件，再回归受影响的现有功能，修复问题后才进入下一项。新增涉及数据结构的功能还必须验证旧数据升级与旧备份恢复；所有新增界面继续支持中英文、明暗主题、键盘操作和减少动画偏好。本轮实际验证结果、执行入口和未覆盖环境记录在 `docs/VERIFICATION.md`。

不包含移动端、团队协作、云同步、在线代码运行、AI 规划和富文本附件。
